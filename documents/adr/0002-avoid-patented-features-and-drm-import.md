# 0002. 特許に当たる表示方式・機能と、DRM を回避する取り込みを作らない

## Status
Accepted

## Context
IdeaMemo #341 ( https://github.com/bannzai/IdeaMemo/issues/341 ) で、日本 (J-PlatPat) と米国 (Google Patents・USPTO の公報) の特許、著作権法の条文を調べた。本サービスは Web で公開し米国からもアクセスできるため、日本と米国の両方で生きている権利に当たらない形にする。調査の結論 (2026-09-26〜27):

- 1 文節 (単語) ずつ、画面の同じ位置に中央揃えで切り替えて表示し、速度をユーザーが設定する RSVP リーダーは、日本・米国で生きている特許に当たらない
- 当たりうるのは、下の表の機能を足した時だけ

| 権利 | 要件の要点 | 当たる機能 |
| --- | --- | --- |
| US 8,903,174 (Spritz、2033-07-09 満了予定) | 各単語の最も認識しやすい文字 (ORP) を、中央より左の定位置に揃えて順に表示する。請求項 19・47 は「中央より左」を要件にしない | ORP を定位置に揃える配置、特定の 1 文字を赤くして定位置に置く表示 |
| US 9,632,661 (Spritz) | 項目の一覧を表示したまま、選んだ項目を別の領域で RSVP 再生する | 本・記事の一覧を表示したままの再生 |
| US 9,997,085 (IBM、2034-11-05 満了予定。年金の状況は要再確認) | 単語ごとの指標で認知負荷を求め、しきい値を超えたら提示速度を一時的に下げる。明細書は「見知らぬ固有名詞」を指標の例に挙げる | 人物名・固有名詞を含む文節の表示時間を延ばす (「名前で少し長く」) |
| US 10,649,612 (Nelson) | 全文を出したまま、時間とともに進むハイライトと、その語の複製を中央に出す | 再生中に全文とハイライトを出す |
| 特許6314555・特許6515523 (大日本印刷) | 形態素で区切った各区切りの文字の見た目を、先頭からの位置で変えて連結して読ませる | 文節の中の文字を位置で色・太さを変える、文節ごとの色のグラデーション |
| 特許7105354 (ACラーニング) | 設定した時間だけ文章を見せ、消した後に内容の質問に答えさせる | 読了後の理解度クイズ |
| 特許5926650 (SRJ)、特開2024-163726 (瞬読) | 読書速度の計測から訓練コースを組む、訓練の種類を選ばせてコースにする | 訓練コースの自動作成・選択 |
| 特許7701192 (日立)、特許7052328 (大日本印刷)、特許6901525・特許6831228 (Z会)、US 11,749,132 (IBM) ほか | カメラ・視線・生体情報で集中度や視点を取り、速度・強調を変える | 視線・カメラ・生体センサーの利用 |
| 特許7634940 (カシオ) | 再生中のタップで単語を選ぶ時、切り替えからの経過時間が短ければ直前の単語を選ぶ | タップでの単語選択の補正 |
| 特表2026-509726 (デシャームズ、審査請求前) | 表示要素と対応する音声を出し、音声が終わったら次の要素に進む | 読み上げ音声との連動 |
| US 12,229,492・US 2024/0419887 A1 (Read Twogether) | 原文と訳文の対を上下交互に並べる表示 (要約だけで判定、継続出願は未読) | 英文の訳の出し入れ (弁理士の確認対象) |
| 著作権法 120 条の 2 第 1 号 | 技術的保護手段の回避を行うプログラムを公衆に提供すると刑事罰 | Kindle などの DRM 付き書籍の取り込み |

## Decision
次を実装しない。変える時は弁理士の確認を経て、この ADR を置き換える ADR を書く。

- 文節 (単語) を中央揃え以外で配置すること。ORP を定位置に揃える配置、特定の 1 文字に色を付ける表示、文節の中の文字の見た目を位置で変える表示、文節ごとの色のグラデーション
- 本・記事の一覧を表示したままの再生
- 固有名詞・人物名で表示時間を延ばすこと。句読点で間をとるのは残す (1997 年出願の US 6,130,968 に既にあり、IBM の指標の例に無い)
- 再生中の全文表示。全文とハイライトは停止中だけ出す
- 読了後の理解度クイズ、読書速度の計測から組む訓練コース
- 視線・カメラ・生体情報の利用
- 再生中のタップでの単語選択に、切り替え直後の補正を入れること。タップは一時停止・再開に使う
- 読み上げ音声との連動 (特表2026-509726 の審査結果が出るまで)
- DRM の付いた書籍 (Kindle 等) を取り込む機能。取り込み口はテキストの貼り付けと DRM の無いファイル (txt・EPUB) だけにする
- 本文をサーバーへ送る・保存する経路 (ADR 0001)

## Consequences
- X の投稿のアプリの機能のうち、「名前で少し長く」だけが減る。人物名の色分け (単語単位で色を変える) は大日本印刷の特許の要件 (区切りの中の文字の位置で見た目を変えて連結する) と違うため、この ADR の対象外として別途判断できる
- 英文の訳の出し入れは、公開前の弁理士の確認に含める (公開前チェックリスト)
- US 8,903,174 と US 9,997,085 は 2027 年 1 月に年金の状況を確認し直す。消滅していれば、この ADR を置き換えて制約を緩められる
- 調査は J-PlatPat と Google Patents の検索範囲に限られ、言い回しの違う特許は漏れている可能性がある
