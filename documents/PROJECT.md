# sokudoku

日本語・英語の文章を、1 語 (日本語は文節) ずつ画面の同じ位置に切り替えて表示し、目を動かさずに速く読む RSVP (Rapid Serial Visual Presentation) 方式の速読リーダー。読む速度 (1 分あたりの文字数・単語数) はユーザーが決める。

企画の出典と特許・権利の調査結果: https://github.com/bannzai/IdeaMemo/issues/341 (本文と 2026-09-27 のコメント 4 件)

## 誰の・どの痛みを解決するか

- 長い文章 (小説・技術書・記事) を、内容を理解したまま今より速く読みたい人
- 作り手自身が使うことを主な目的にする (2026-09-28 の立ち上げ時に確認)
- きっかけは、RSVP で 18 万文字を 3 時間で読めたという投稿 ( https://x.com/hanagasa_ai/status/2103793989120135545 )。投稿のアプリと同等の体験を、日本語と英語で提供する

## MVP の機能

| 機能 | 内容 |
| --- | --- |
| 取り込み | テキストの貼り付けと、DRM の無いファイル (青空文庫の txt・プレーンテキスト・EPUB) の読み込み |
| 日本語の分割 | 文節に区切る。句読点で間をとる |
| 英語の分割 | 1 単語ずつ |
| 表示 | 1 文節 (単語) ずつ、画面の同じ位置に中央揃えで表示する |
| 速度 | 1 分あたりの文字数 (英語は単語数) をユーザーが設定する。再生中の変更も可 |
| 操作 | space で一時停止・再開、キーボードで速度変更・前後移動。画面のボタンでも同じ操作ができる |
| 全文表示 | 停止中だけ全文を出し、現在位置をハイライトする (再生中は全文を出さない) |
| 英文の日本語訳 | 再生中の単語を含む文の日本語訳を、T キーと画面のボタンで出し入れする。翻訳は Chrome 内蔵の Translator API で端末内で行う。使えない環境ではボタンを無効にして理由を表示する |
| 読了画面 | 読んだ時間と実効速度を表示する |
| 設定・位置の保存 | 速度などの設定と読書位置をブラウザのストレージに保存する |
| UI の言語 | 日本語のみ |

機能ごとの特許・権利上の制約は `documents/adr/0002-avoid-patented-features-and-drm-import.md` を正とする。

## 技術方針

- Web アプリ。Next.js の静的書き出しを GitHub Pages (https://bannzai.github.io/sokudoku/) で配信する。本文はブラウザ内だけで処理し、サーバーに送らず保存もしない (`documents/adr/0001-static-export-on-github-pages.md`)
- DB・認証・課金は持たない (MVP)。特定商取引法に基づく表記は課金を入れる時に用意する
- アクセス解析は Cloudflare Web Analytics (Cookie を使わない beacon)。読込テキストは送らない
